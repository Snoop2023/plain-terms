# 向量 vector

## 人话

一串有顺序的数，比如 [3, 1, 4]。几何上是一支带方向和长度的箭头。AI 里每个 token 都变成一个几百维的向量。

## 英文释义

vector「运载者」：把一个点从起点「运」到终点的那支箭头。生物学里传播病毒的蚊子也叫 vector。

## 英文来源

拉丁 *vehere*「运载」，vehicle（车辆）同根。哈密顿 1846 年用于数学。

## 中文来源

向 = 方向，有方向的量。物理里也叫「矢量」，矢 = 箭。
