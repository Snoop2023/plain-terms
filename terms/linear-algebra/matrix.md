# 矩阵 matrix

## 造词现场

要处理的问题是：一堆数到一堆数之间的那种整体动作，怎么写下来、怎么算。西尔维斯特 1850 年给了它一个很哲学的名字：matrix 本义是母体、子宫，他觉得这张表是「生出行列式的母体」。中文借了制图的工具：矩是画方形的曲尺，阵是排列。

## 人话

排成行和列的数字表格。它的真正用途是做「变换机器」：一个向量乘上矩阵，变成另一个向量（旋转、拉伸、投影）。神经网络每一层的核心就是一次矩阵乘法。

## 英文释义

matrix 本义是「母体、子宫」，引申为孕育东西的模子。西尔维斯特 1850 年认为它是「生出行列式的母体」。

## 英文来源

拉丁 *mater*「母亲」。

## 中文来源

矩 = 画方形的曲尺（「规矩」的矩），阵 = 排列。数字排成方阵。中文比英文直白。
