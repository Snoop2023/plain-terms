人话术语

一个词，四种讲法，一群不同背景的人各自说一遍

怎么用
方

方差variance

概率与信息 ✅ 中文其实准，知道字的本义就懂

造词现场

要处理的问题是：两组数平均值一样，一组很稳、一组忽上忽下，「抖」这件事怎么量。办法是每个数减平均值、平方、再取平均。名字借 vary「变化」。中文这两个字要小心：方是平方，差是偏差 —— 跟方程的「方」（方阵）来历无关。

人话

衡量一组数「抖得多厉害」。每个数减去平均值、平方、再取平均。方差大 = 很分散，方差小 = 很集中。开根号就是标准差。

英文释义

vary「变化」→ variance「变动的程度」。

英文来源

拉丁 variare「改变」。费希尔 1918 年定为统计术语。

中文来源

方 = 平方，差 = 偏差。注意：这个「方」和方程的「方」（方阵）来源完全不同。
