一个词，四种讲法，一群不同背景的人各自说一遍

怎么用
参

参数parameter

基础数学 ✅ 中文其实准，知道字的本义就懂

造词现场

要处理的问题是：一个公式里，主角变量之外还站着几个数，它们在决定这个公式长什么样。这几个数怎么称呼。名字是拼出来的：para「旁边」+ meter「度量」—— 站在旁边的度量。中文借「参」：参与。参数 = 参与结果的数。

人话

决定公式或模型「长什么样」的可调数字。y = kx + b，换一组 k、b 就是另一条直线，k、b 就是参数。神经网络的参数就是那几百万个权重。

英文释义

para「旁边」+ meter「度量」。不是主角变量 x，而是站在旁边控制公式形状的量。

英文来源

希腊 para + metron。

中文来源

参 = 参与。参数 = 参与决定结果的数。
