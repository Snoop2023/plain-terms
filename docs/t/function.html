怎么用
函

函数function

基础数学 ✅ 中文其实准，知道字的本义就懂

造词现场

要处理的问题是：一个量变了，另一个量跟着变，这层关系该怎么称呼。莱布尼茨描述曲线上一点在走动，欧拉把它写成 f(x)。名字借了拉丁 functio —— 履行、执行一份职责：一个输入进来，输出按规矩执行出来。中文这边，李善兰 1859 年另借了一个字：「函」是装信的套子、含着的盒子，函数就是含有另一个变量的数。

人话

一台「输入→输出」的机器。给它一个 x，它按固定规则给出一个 y；同一个 x 永远得到同一个 y。x 一变，y 跟着变。

英文释义

function 日常就是「功能、作用」。「y is a function of x」= y 由 x 的作用决定。

英文来源

拉丁 functio「执行、履行」。莱布尼茨 17 世纪末首用于数学。

中文来源

李善兰 1859《代数学》：「凡此变数中函彼变数者，则此为彼之函数。」函 = 包含（信函 = 装信的套子）。函数 = 里面含着另一个变量的数。

吐槽役非本专业读者编者视角

「函数」两个字我念了十二年，才知道「函」是包含的意思。课本第一页就该把李善兰这句话印上去。

C 语言老兵底层软件 / C编者视角

写过 C 的秒懂：int f(int x) { return 2*x + 1; }。数学里的函数，就是没有副作用、同样输入永远同样输出的 C 函数。

数学系路人数学专业编者视角

别把函数等同于公式。函数本质是一张对照表：每个 x 对应唯一一个 y。公式只是把这张表压缩写出来的一种方式。
