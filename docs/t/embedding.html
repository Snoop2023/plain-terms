嵌入embedding

AI 专用词 ⚠️ 中文有歧义或误导，先看英文

造词现场

要处理的问题是：词在词典里是离散的编号，模型算的是连续的向量，中间怎么接上。办法是给每个词配一行向量，拿编号去表里查。名字借 embed —— 嵌进去：把一个东西安放进另一个空间。中文直译。

人话

给每个 token 配一个向量。做法是拿 token 的 ID 去一张大表里查一行，这张表是训练出来的，意思相近的词，查出来的向量也相近。GPT 拿到文字后做的第一件事就是查这张表。

英文释义

em「放进」+ bed「床」= embed「嵌进去、安放进去」。数学上指把一个东西放进另一个空间：把离散的词「放进」连续的向量空间。

英文来源

古英语 bedd「床」。

中文来源

直译。⚠️ 和「嵌入式系统 embedded system」是同一个英文词根，意思毫无关系。

嵌入式老兵嵌入式 / 固件编者视角

我以为终于到了我的主场，结果是查表。不过确实就是 const float table[VOCAB][DIM]，用 token ID 当下标取一行。区别只有一个：这张表是训练出来的，不是手写的。

吐槽役非本专业读者编者视角

炼丹师AI 训练 / 工程编者视角

ID 只是编号。猫是 3、狗是 4，不代表猫狗比猫和汽车更像。查出来的向量才有「距离」的意义，像的词靠得近。

数学系路人数学专业编者视角

经典例子：king − man + woman ≈ queen。向量相减能表示「关系」。
