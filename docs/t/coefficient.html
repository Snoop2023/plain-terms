一个词，四种讲法，一群不同背景的人各自说一遍

怎么用
系

系数coefficient

基础数学 ✅ 中文其实准，知道字的本义就懂

造词现场

要处理的问题是：写 3x 的时候，3 和 x 地位不一样。那个和变量绑在一起、决定影响有多大的数，怎么称呼。英文把 co「一起」+ efficient「起作用的」拼起来。中文借「系」—— 系在、绑在。系数 = 绑在变量身上的数。

人话

乘在变量前面的数。3x 里的 3 就是系数，它决定 x 的影响有多大。

英文释义

co「一起」+ efficient「起作用的」= 和变量一起起作用的那个数。

英文来源

拉丁 co- + efficiens「产生效果」。16 世纪韦达用于代数。

中文来源

系 = 系在、绑在。系数 = 绑在变量身上的数。
