概念是倒着来的：先有人解决一个具体问题，事后才给这件事取了个名字。所以每个词条的第一段是造词现场 —— 造这个词之前，人们在解决什么。

评论区里说话的是普通人，跟你一样。大脑是预测机器：看到相似的人懂了，它就会推出「我也能懂」。教科书只给你一个样本，评论给的是好几个。

代
代数@algebra基础数学✅

用字母代替具体的数来算。不写 3+5，写 a+b，这样一条规则对所有数都成立。

造词现场要处理的问题是：数还没算出来，先怎么摆布它们。花剌子模 820 年前后写了一本手册，专讲移项、合并这类手法。书名里的 al-jabr 意思是「把断的接回去」，本指接骨，用在算式里就是把负项挪到另一边变成正项。

函
函数@function基础数学✅

一台「输入→输出」的机器。给它一个 x，它按固定规则给出一个 y；同一个 x 永远得到同一个 y。x 一变，y 跟着变。

造词现场要处理的问题是：一个量变了，另一个量跟着变，这层关系该怎么称呼。莱布尼茨描述曲线上一点在走动，欧拉把它写成 f(x)。名字借了拉丁 functio —— 履行、执行一份职责：一个输入进来，输出按规矩执行出来。

参
参数@parameter基础数学✅

决定公式或模型「长什么样」的可调数字。y = kx + b，换一组 k、b 就是另一条直线，k、b 就是参数。神经网络的参数就是那几百万个权重。

造词现场要处理的问题是：一个公式里，主角变量之外还站着几个数，它们在决定这个公式长什么样。这几个数怎么称呼。名字是拼出来的：para「旁边」+ meter「度量」—— 站在旁边的度量。中文借「参」：参与。参数 = 参与结果的数。

方
方程@equation基础数学⚠️

带未知数的等式，左边 = 右边。解方程就是找出让两边真正相等的那个未知数。

造词现场要处理的问题是：几个未知数缠在一起，怎么把它们解出来。《九章算术》那边的办法是把系数并排成方阵、一行行消去，这套动作本身被叫作方程：方是方阵，程是计量。西边借的是拉丁 aequare「使相等」，管这条式子叫等式。

导数@derivative微积分⚠️

变化率。x 挪一点点，y 跟着变多少，这个比例就是导数。画在图上，是曲线在这一点切线的斜率。AI 里：某个参数微调一点，loss 变多少。

一个极小极小的变化量。dx = x 的一丁点变化，dy = 跟着产生的 y 的一丁点变化。导数就是 dy ÷ dx。

研究「变化」和「累加」的数学。微分管「此刻变得多快」，积分管「一共累积了多少」，两者互为逆运算。

梯
梯度@gradient微积分✅

多个输入时，每个输入各有一个导数，把它们排成一个向量就是梯度。它指向「函数涨得最快」的方向；反着走就是下坡最快，这就是梯度下降。

造词现场要处理的问题是：输入有几百个，每个都在影响结果，该往哪个方向调。把每个输入的导数排成一排，就得到一支箭头 —— 它指向上升最快的方向。名字借了 grade —— 坡度。中文借「梯」+「度」：像梯子一样一级一级的陡度。

卷
卷积@convolution线性代数✅

拿一个小窗口沿着数据滑动，每到一个位置就把窗口里的数加权求和。信号里的理解：每个时刻的输入都会留下一段「余波」，当前输出是过去所有余波叠在一起的结果，也就是「瞬时行为的持续性结果」。FIR 滤波器、CNN 的核心都是它。

造词现场要处理的问题是：一个输入进来，它的影响不会立刻消失，会拖一段尾巴。当前的结果该怎么算。答法是把历史上每个输入至今剩下的影响全加起来。名字借拉丁 convolvere「卷起来」：把一段响应翻过来、卷着滑过去。

特
特征值@eigenvalue线性代数⚠️

大多数向量被矩阵一乘，方向就变了。但有少数特殊方向，乘完只是被拉长或缩短，方向不变。这些方向叫特征向量，拉伸的倍数叫特征值。它们描述了这个矩阵「最本质的行为」。

造词现场要处理的问题是：一个矩阵乘上去，多数箭头方向都歪了 —— 有没有哪些方向歪不了。答案是有，而那些方向的伸长倍数刻画了这个矩阵最本质的行为。希尔伯特那一圈德国人用德语 eigen —— 自己的、固有的。

线性@linear线性代数✅

满足两条规则：输入放大 2 倍，输出也放大 2 倍；两个输入分开处理再相加，等于先相加再处理。矩阵乘法是线性的，所以神经网络必须在层与层之间插非线性函数，不然叠 100 层也只相当于 1 层。

交叉熵@cross-entropy概率与信息🔁

拿「模型猜的概率」去给「真实答案」打分。模型给真实答案的概率越高，交叉熵越低。GPT 训练时压低的那个 loss 就是它；只有一个正确答案时，它就等于「−log(正确答案的概率)」。

似
似然@likelihood概率与信息⚠️

概率和似然是同一个公式，只是问法反过来。概率：参数定了，问「这组数据出现的可能性多大」。似然：数据已经摆在这，问「哪组参数最能解释它」。训练模型 = 找让真实数据似然最大的参数。

造词现场要处理的问题是：参数和数据之间的问答方向反过来之后，该怎么称呼。已知参数问数据，那是概率；已经拿着数据反问「哪组参数最能解释它」，费希尔 1921 年把这件事正式和 probability 分开……

方
方差@variance概率与信息✅

衡量一组数「抖得多厉害」。每个数减去平均值、平方、再取平均。方差大 = 很分散，方差小 = 很集中。开根号就是标准差。

造词现场要处理的问题是：两组数平均值一样，一组很稳、一组忽上忽下，「抖」这件事怎么量。办法是每个数减平均值、平方、再取平均。名字借 vary「变化」。中文这两个字要小心：方是平方，差是偏差 —— 跟方程的「方」（方阵）来历无关。

期望@expectation概率与信息⚠️

按概率加权的平均值。掷骰子：1~6 每个乘以 1/6 再相加 = 3.5。意思是「重复无数次，平均下来是多少」。和「希望」没有关系。

正
正则化@regularizationAI 专用词⚠️

给模型加约束或惩罚，不让参数变得太大、模型变得太复杂，从而防止过拟合。常见做法：在 loss 上加一项「参数越大罚越多」（权重衰减），或训练时随机关掉一些神经元（dropout）。

造词现场要处理的问题是：参数想变多大就变多大，模型就会拿极端参数硬背噪声，怎么拦住它。办法是加惩罚：参数越大罚越多。名字借拉丁 regula「直尺、规则」—— 给模型立点规矩。中文把 regular 固定译成「正则」。

没搜到。要不要新加一个词条？

几条串起来的规律

  • 李善兰一个人造了一大批词：函数、代数、微分、积分。他用的是古义（函 = 包含），今天读着别扭，其实很准。
  • 同一个汉字可能不同源：方程的「方」是方阵，方差的「方」是平方。
  • 英文同根词能互相提示：tensor 和 attention 都来自 tendere「伸、拉」；norm、normalization、范数是一家；derivative 和金融衍生品是同一个词。
  • 中文比英文直白的：积分、代数、矩阵、似然、权重。英文更好用的：equation、inference、softmax、robust。
