人话术语

一个词，四种讲法，一群不同背景的人各自说一遍

教材给每个词一个定义。看懂一个定义靠的是运气。这里换成另一套办法： 同一个词，让不同背景的人各讲一遍 —— 写过 BMS 的人怎么理解导数， 搞数据库的人怎么理解注意力。看得懂其中一条就够，因为「跟我差不多的人懂了」 本身就是最有效的信号。

✅ 中文其实准，知道字的本义就懂 ⚠️ 中文有歧义或误导，先看英文 🔁 两边都不直观，只能记住它指什么

基础数学 6

代数algebra✅

用字母代替具体的数来算。不写 3+5，写 a+b，这样一条规则对所有数都成立。

几何geometry⚠️

研究形状、大小、位置、角度的数学：三角形、圆、平行线这些。

基础数学 · 0 条评论
函数function✅

一台「输入→输出」的机器。给它一个 x，它按固定规则给出一个 y；同一个 x 永远得到同一个 y。x 一变，y 跟着变。

基础数学 · 3 条评论
参数parameter✅

决定公式或模型「长什么样」的可调数字。y = kx + b，换一组 k、b 就是另一条直线，k、b 就是参数。神经网络的参数就是那几百万个权重。

基础数学 · 0 条评论
方程equation⚠️

带未知数的等式，左边 = 右边。解方程就是找出让两边真正相等的那个未知数。

基础数学 · 3 条评论
系数coefficient✅

乘在变量前面的数。3x 里的 3 就是系数，它决定 x 的影响有多大。

基础数学 · 0 条评论

微积分 5

导数derivative⚠️

变化率。x 挪一点点，y 跟着变多少，这个比例就是导数。画在图上，是曲线在这一点切线的斜率。AI 里：某个参数微调一点，loss 变多少。

微积分 · 4 条评论
微分differential✅

一个极小极小的变化量。dx = x 的一丁点变化，dy = 跟着产生的 y 的一丁点变化。导数就是 dy ÷ dx。

微积分 · 0 条评论
微积分calculus✅

研究「变化」和「累加」的数学。微分管「此刻变得多快」，积分管「一共累积了多少」，两者互为逆运算。

微积分 · 0 条评论
梯度gradient✅

多个输入时，每个输入各有一个导数，把它们排成一个向量就是梯度。它指向「函数涨得最快」的方向；反着走就是下坡最快，这就是梯度下降。

微积分 · 3 条评论
积分integral✅

把无数个碎片累加成总量。每一小段时间的电流 × 时间，全部加起来就是总电量。画在图上，是曲线下面的面积。

微积分 · 3 条评论

线性代数 9

卷积convolution✅

拿一个小窗口沿着数据滑动，每到一个位置就把窗口里的数加权求和。信号里的理解：每个时刻的输入都会留下一段「余波」，当前输出是过去所有余波叠在一起的结果，也就是「瞬时行为的持续性结果」。FIR 滤波器、CNN 的核心都是它。

线性代数 · 8 条评论
向量vector✅

一串有顺序的数，比如 [3, 1, 4]。几何上是一支带方向和长度的箭头。AI 里每个 token 都变成一个几百维的向量。

线性代数 · 0 条评论
张量tensor⚠️

AI 里就是多维数组。0 维是一个数，1 维是向量，2 维是矩阵，3 维以上统称张量。GPT 里常见的 (B, T, C) 就是一个 3 维张量。

线性代数 · 3 条评论
标量scalar✅

只有大小、没有方向的一个数。温度、质量都是标量。代码里就是一个 float。

线性代数 · 0 条评论
正交orthogonal✅

两个向量互相垂直。直观上就是「互不相干」：沿一个方向走，在另一个方向上的位置完全不变。

线性代数 · 0 条评论
特征值eigenvalue⚠️

大多数向量被矩阵一乘，方向就变了。但有少数特殊方向，乘完只是被拉长或缩短，方向不变。这些方向叫特征向量，拉伸的倍数叫特征值。它们描述了这个矩阵「最本质的行为」。

线性代数 · 3 条评论
矩阵matrix✅

排成行和列的数字表格。它的真正用途是做「变换机器」：一个向量乘上矩阵，变成另一个向量（旋转、拉伸、投影）。神经网络每一层的核心就是一次矩阵乘法。

线性代数 · 3 条评论
线性linear✅

满足两条规则：输入放大 2 倍，输出也放大 2 倍；两个输入分开处理再相加，等于先相加再处理。矩阵乘法是线性的，所以神经网络必须在层与层之间插非线性函数，不然叠 100 层也只相当于 1 层。

线性代数 · 0 条评论
范数norm🔁

向量的「长度」或「大小」。最常用的 L2 范数：每个分量平方、加起来、开根号，就是勾股定理。正则化用它衡量参数有多大。

概率与信息 6

交叉熵cross-entropy🔁

拿「模型猜的概率」去给「真实答案」打分。模型给真实答案的概率越高，交叉熵越低。GPT 训练时压低的那个 loss 就是它；只有一个正确答案时，它就等于「−log(正确答案的概率)」。

概率与信息 · 3 条评论
似然likelihood⚠️

概率和似然是同一个公式，只是问法反过来。概率：参数定了，问「这组数据出现的可能性多大」。似然：数据已经摆在这，问「哪组参数最能解释它」。训练模型 = 找让真实数据似然最大的参数。

概率与信息 · 3 条评论
方差variance✅

衡量一组数「抖得多厉害」。每个数减去平均值、平方、再取平均。方差大 = 很分散，方差小 = 很集中。开根号就是标准差。

概率与信息 · 0 条评论
期望expectation⚠️

按概率加权的平均值。掷骰子：1~6 每个乘以 1/6 再相加 = 3.5。意思是「重复无数次，平均下来是多少」。和「希望」没有关系。

概率与信息 · 3 条评论
熵entropy🔁

平均「意外程度」。越难猜的事，结果出来越让人意外，熵越高。抛均匀硬币熵是 1 bit；结果早就确定的事熵是 0。信息论里：给结果编码，平均最少要多少 bit。

概率与信息 · 4 条评论
随机stochastic✅

带不确定性、每次结果可能不同。「随机梯度下降」= 每次不用全部数据，只抽一小批来估算下坡方向，快，但方向有噪声。

AI 专用词 17

logits🔁

模型最后一层吐出来的原始分数，还没换成概率，可正可负、大小不限。送进 softmax 才变成概率。

AI 专用词 · 2 条评论
softmax✅

把一组任意大小的分数变成概率：全变成正数，加起来等于 1。分最高的拿到最大的概率，但不独占，其他选项也留一点机会。

AI 专用词 · 2 条评论
偏置bias⚠️

加在结果上的一个常数，让输出整体往上或往下平移。y = wx + b 里的 b。没有它，直线永远只能过原点。

AI 专用词 · 2 条评论
嵌入embedding⚠️

给每个 token 配一个向量。做法是拿 token 的 ID 去一张大表里查一行，这张表是训练出来的，意思相近的词，查出来的向量也相近。GPT 拿到文字后做的第一件事就是查这张表。

AI 专用词 · 4 条评论
归一化normalization⚠️

把一组数缩放到统一的尺度。具体缩成什么样看上下文，常见三种：缩到 0~1；调成平均 0、方差 1（BatchNorm、LayerNorm 就是这种）；让一组数加起来等于 1，变成概率（softmax 就是这种）。

AI 专用词 · 0 条评论
拟合fit✅

调整模型的参数，让它的曲线尽量贴着数据点走。

AI 专用词 · 0 条评论
损失loss✅

一个分数，表示模型这次猜得有多错。越小越好。训练的全部目标就是把它一点点压低。

AI 专用词 · 0 条评论
推理inference⚠️

把训练好的模型拿来用：喂进输入，跑一遍前向计算，拿到输出。和「训练」相对，训练是改参数，推理是参数固定只跑计算。你用 ChatGPT 聊天，服务器那边做的就是推理。

AI 专用词 · 3 条评论
权重weight✅

每个输入要乘上的系数，代表这个输入对输出的影响有多大。权重大 = 这个输入说话分量重。训练模型，本质上就是不断调整这几百万个权重。

AI 专用词 · 0 条评论
正则化regularization⚠️

给模型加约束或惩罚，不让参数变得太大、模型变得太复杂，从而防止过拟合。常见做法：在 loss 上加一项「参数越大罚越多」（权重衰减），或训练时随机关掉一些神经元（dropout）。

AI 专用词 · 4 条评论
泛化generalization✅

模型在没见过的新数据上也做得好。这才是训练真正要的东西：不是记住题目，而是学会背后的规律。

AI 专用词 · 0 条评论
注意力attention⚠️

每个位置都去看其它位置，按「和我有多相关」打分，再按分数加权，把其它位置的信息取过来。比如句子里的「它」，会给前文中它指代的那个名词打高分。这是 Transformer 的核心。

AI 专用词 · 3 条评论
激活函数activation function🔁

每一层矩阵乘法之后加的一个非线性函数，比如 ReLU（负数变 0，正数不变）、tanh（压到 −1 到 1 之间）。作用是给网络加「弯折」，没有它，多层网络就退化成一层。

AI 专用词 · 0 条评论
词元token⚠️

文本被切成的最小单位，可能是一个字、半个单词、一个标点或一个空格。模型不直接读文字，读的是一串 token 编号。

AI 专用词 · 0 条评论
超参数hyperparameter⚠️

训练开始前由人来定的设置，比如学习率、层数、批大小。普通参数（权重）是训练自己学出来的；超参数是人手拧的旋钮。

AI 专用词 · 0 条评论
过拟合overfitting✅

模型把训练数据连带噪声一起背下来了，训练集上分数很好，换一批没见过的数据就不行。就像学生背答案不理解题，换道题就不会。

AI 专用词 · 2 条评论
鲁棒robust⚠️

稳健、抗干扰。输入有噪声、环境变化了，结果依然靠得住。

几条串起来的规律

  • 李善兰一个人造了一大批词：函数、代数、微分、积分。他用的是古义（函 = 包含），今天读着别扭，其实很准。
  • 同一个汉字可能不同源：方程的「方」是方阵，方差的「方」是平方。
  • 英文同根词能互相提示：tensor 和 attention 都来自 tendere「伸、拉」；norm、normalization、范数是一家；derivative 和金融衍生品是同一个词。
  • 中文比英文直白的：积分、代数、矩阵、似然、权重。英文更好用的：equation、inference、softmax、robust。
